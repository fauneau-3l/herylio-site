# Site officiel Herylio

Site statique de Herylio — 3L Généalogie.

## Mise en ligne sur GitHub

1. Ouvrir le dépôt `herylio-site` sur GitHub.
2. Cliquer sur **Add file**, puis **Upload files**.
3. Décompresser l’archive fournie.
4. Faire glisser **le contenu** du dossier `herylio-site-main` dans la page GitHub (et non le dossier lui-même).
5. En bas de la page, cliquer sur **Commit changes**.

GitHub Pages republiera ensuite automatiquement le site. Les fichiers `index.html`, `styles.css`, `legal.css` et `script.js` doivent rester à la racine du dépôt, à côté du dossier `assets`.

## Pages

- `index.html` : accueil et présentation de Herylio
- `confidentialite.html` : politique de confidentialité
- `mentions-legales.html` : mentions légales
- `notes-version.html` : nouveautés de l’application
